### How to Write
1. 自分の名前のbranchを生やす
1. `articles/(カテゴリ名)`内にmdで記事を作成  
    `articles/templete.md`を参考に書いてくださると揃った書き方になると思います
1. `datas/(カテゴリ名).js`内にある配列にカンマを打ちタイトルと記事のパスを追加  
    `title: "(ツール名)",`  
    `file: PATH+"(ファイル名).md"`  
1. プルリクエストを送信
